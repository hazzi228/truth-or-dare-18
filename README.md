# 🔞 Правда или Действие 18+ — Telegram Mini App

```
truth-or-dare-18/
├── webapp/index.html   ← сама игра (один файл, без сборки)
└── bot/bot.py          ← бот, который открывает игру в Telegram
```

## Что умеет игра
- Подтверждение возраста 18+ на входе
- Игра для двоих: два имени (первое берётся из Telegram), сохраняются между запусками
- 4 уровня: 😏 Флирт → 🌶 Горячо → 🔥 Без тормозов → 🔞 Грязно, 296 заданий, 15 поз со схемами — сыгранные не повторяются, пока не пройдёте весь уровень
- Режим «нарастание жара» — уровень повышается каждые 2 круга
- Задания с партнёром: `{p}` заменяется на имя второго игрока
- Очки: правда +1, действие +2, пропуск −1; таблица лидеров
- Таймер для действий (сам берёт время из текста: «30 секунд», «1 минута»)
- Вибрация (Haptic Feedback) и кнопка «Назад» Telegram
- Задания не повторяются, пока не закончится колода

Свои задания добавляются в объект `TASKS` в `webapp/index.html`.

## Шаг 1. Выложить игру (GitHub Pages — бесплатно)
1. Создайте на GitHub публичный репозиторий `truth-or-dare-18`.
2. Загрузите туда `webapp/index.html` (в корень репозитория).
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root` → Save.
4. Через минуту игра будет доступна по адресу `https://<ваш-ник>.github.io/truth-or-dare-18/`.

Подойдёт любой хостинг с HTTPS: Netlify, Vercel, Cloudflare Pages (можно просто перетащить папку `webapp`).

## Шаг 2. Создать бота
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. (Опционально, без кода) `/newapp` → выберите бота → укажите URL игры — получите прямую ссылку вида `t.me/<бот>/<app>`.
3. (Опционально) `/mybots` → бот → Bot Settings → Menu Button → URL игры.

## Шаг 3. Запустить бота
```powershell
cd bot
pip install -r requirements.txt
$env:BOT_TOKEN="123456:ABC..."
$env:WEBAPP_URL="https://<ваш-ник>.github.io/truth-or-dare-18/"
python bot.py
```
Напишите боту `/start` → «🔥 Играть».

> Если вы настроили Menu Button или `/newapp` через BotFather, бот на Python можно вообще не запускать — игра будет открываться и без него.

## Важно
По правилам Telegram контент 18+ должен быть помечен. Игра содержит возрастной барьер; не публикуйте бота в открытых каталогах для широкой аудитории.

## Установка на iPhone как приложение
1. Откройте https://hazzi228.github.io/truth-or-dare-18/ в **Safari**.
2. Нажмите «Поделиться» → «На экран „Домой“» → «Добавить».
3. На экране появится иконка. Игра открывается на весь экран и работает без интернета.
